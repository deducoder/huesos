# Vision: huesos-mono

huesos-mono es una aplicación web para que estudiantes de medicina memoricen los
206 huesos del cuerpo humano. Muestra un esqueleto completo que se puede
explorar y seleccionar hueso por hueso, y un modo test que invierte la relación:
presenta el esqueleto sin etiquetas, pregunta por un hueso concreto, valida lo
que el estudiante escribe y lo corrige en el momento cuando se equivoca. Existe
porque estudiar osteología con un atlas en papel obliga a tapar la respuesta con
la mano y a corregirse uno mismo — un bucle lento, sin registro de en qué huesos
se falla. La aplicación cierra ese bucle: ver, responder, ser corregido, repetir.

## Outcomes

The changes in the world this project is trying to cause.

| Outcome | Description |
|---------|-------------|
| **Reconocimiento sobre memorización ciega** | El estudiante asocia el nombre a una forma y una posición en el esqueleto, no a una posición en una lista |
| **Corrección inmediata** | Un error se corrige en el instante en que se comete, con el nombre correcto a la vista, nunca al final de una tanda |
| **Doble nomenclatura sin doble estudio** | El español y el término de la Terminologia Anatomica se aprenden juntos, porque ambos se dan por válidos y el otro siempre se muestra |
| **El fallo dirige el estudio** | El sistema sabe en qué huesos falla el estudiante y puede preguntarle esos primero |
| **Cero fricción para empezar** | Se abre en el navegador y se estudia: sin cuenta, sin instalación, sin conexión obligatoria |
